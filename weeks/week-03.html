進位、補數、字元編碼與 big/little endian。

查看完整章節對照與 MARIE–MIPS 概念橋接

核心概念

  • 位元與編碼：電腦儲存的是位元樣式；同一串位元可依情境解讀為整數、字元、指令或浮點數。資料型態不是位元本身，而是解讀規則。
  • Two's complement：n 位元 two's complement 範圍為 -2^(n-1) 到 2^(n-1)-1。負數可由正數取反加一得到。加減法硬體可共用同一個加法器。
  • 位元延伸：有號數做 sign extension，無號數做 zero extension。若把有號/無號混用，常造成條件判斷錯誤。
  • Endianness：Little endian 與 big endian 決定多位元組資料在記憶體中的 byte 順序。它不改變暫存器中的數值，只影響記憶體表示與資料交換。

本週自學導讀

位元沒有天生的資料型態。正確解讀必須同時知道位元寬度、signedness、編碼規則與 byte 順序；少掉任何一項都可能得到另一個完全不同的值。

概念推導

Two's complement 的權重觀點

n-bit two's complement 的最高位權重是 -2^(n-1)，其餘位元仍是正的 2 的冪。這個觀點可直接解讀負數，不必每次都取反加一。例如 11010110 的值是 -128+64+16+4+2=-42。

Carry out 是無號加法超出 n bits 的訊號；signed overflow 則表示有號結果超出可表示範圍。兩者判斷的數學模型不同，不能互換。

Byte address 與 Endianness

Byte-addressed memory 中每個位址指向 8 bits。32-bit word 會佔用四個連續位址。Little endian 把最低有效 byte 放在最低位址，big endian 則把最高有效 byte 放在最低位址。

Endianness 不會顛倒一個 byte 內的 bit，也不會改變暫存器看到的數值。它只在多 byte 資料被拆到記憶體或通訊封包時產生差異。

Worked example

同一位元樣式的三種解讀

解讀 8-bit pattern 11010110，並排列 0x12345678 在 little-endian memory 的四個 bytes。

  1. Unsigned：128+64+16+4+2 = 214。
  2. Signed two's complement：214-256 = -42。
  3. 若只當作單一 8-bit code，其語意還需由字元集或通訊協定決定。
  4. 0x12345678 的 bytes 為 12、34、56、78；little endian 由低位址起依序存 78、56、34、12。

結論：位元樣式相同不代表值相同；metadata 與使用情境決定解讀。

常見誤解

  • 把 sign bit 當成 signed-magnitude 的正負號。
  • 用 carry out 判斷 signed overflow。
  • 把 little endian 誤解為每個 byte 的 bits 也反向。

自我檢核

先在紙上作答，再展開核對。能說明理由，才算真正掌握。

1. 8-bit 11111111 分別代表多少 unsigned 與 signed 值？

Unsigned 是 255；two's complement signed 是 -1。

2. 兩個負數相加得到正數時，carry out 一定能指出 overflow 嗎？

不能只看 carry out。Signed overflow 應看兩個 operand 同號而結果異號。

講義筆記

二進位與十六進位轉換是後續看 instruction encoding、cache address breakdown 的基本功。十六進位每一位剛好對應 4 bits，適合表達 32-bit 指令與位址。

Overflow 只對固定寬度的有號運算有意義。兩個正數相加得到負數、或兩個負數相加得到正數，就是 two's complement overflow 的典型跡象。

資料對齊（alignment）會影響硬體存取效率。MIPS word 通常要求 4-byte alignment，位址最低兩個 bit 應為 00。

學習路徑

  1. 觀察問題：先辨認本週主題要解決的現象，例如程式變慢、指令相依、cache miss 或位元解讀錯誤。
  2. 建立模型：把問題抽象成本週核心術語，並畫出資料、控制或位址如何流動。
  3. 套用方法：使用公式、指令格式、pipeline 時序表或 cache 位址切割完成分析。
  4. 檢查結果：確認單位、暫存器內容、控制訊號、hit/miss 或 cycle 數是否一致。
  5. 連回效能：說明這個主題如何影響 CPU time、CPI、correctness 或 memory behavior。
練習任務：請使用幾個 8-bit patterns，要求分別以 unsigned、signed、ASCII 解讀，體會「位元樣式」與「意義」的分離。

例題與講解

8-bit two's complement

+18 = 0001 0010
-18 = 1110 1110  # invert 0001 0010 => 1110 1101, plus 1

以 8-bit 來看，1110 1110 若解讀為 unsigned 是 238，若解讀為 signed 是 -18。
