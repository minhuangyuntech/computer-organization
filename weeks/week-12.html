pipeline hazard、branch penalty 與 branch optimization。

查看完整章節對照與 MARIE–MIPS 概念橋接

核心概念

  • Structural hazard：硬體資源不足造成衝突，例如同一 cycle 需要同一個 memory 同時取指令與讀資料。可用分離 instruction/data memory 或增加資源解決。
  • Data hazard：後續指令需要前一指令尚未寫回的結果。常見解法是 forwarding/bypassing；若資料仍來不及，如 load-use，就必須 stall。
  • Control hazard：branch/jump 改變 PC，使下一個要取的指令不確定。解法包含 stall、predict not taken、branch prediction 與延遲槽等。

本週自學導讀

Hazard 是下一條指令在預定 cycle 無法取得正確資料或正確 PC。處理方式只有三類：提早提供結果、延後使用者，或推測後在錯誤時清除。

概念推導

RAW 與 Forwarding 的時序條件

五級 in-order MIPS 最常見的是 read-after-write。ALU 結果在 EX 後可從 EX/MEM 或 MEM/WB register forwarding 到下一指令的 EX input，不必等到 WB 寫回 register file。

Load 的資料到 MEM 結束才取得。緊接的使用者在下一 cycle 進 EX 時仍太早，因此即使有 forwarding，典型 load-use pair 仍需一個 stall。

Control Hazard 與精確狀態

Branch 結果確定前，fetch 不知道正確下一個 PC。Predict-not-taken 可先取 PC+4；若判斷錯誤，必須 flush 已進入 pipeline 的錯誤路徑指令。

Flush 的關鍵是阻止錯誤指令更新架構狀態，例如將它們的 RegWrite、MemWrite 控制變為 0。只丟棄指令文字而未清除控制，仍可能破壞結果。

Worked example

估算 Branch Misprediction 對 CPI 的影響

Branch 佔 20%，misprediction rate 10%，每次錯誤 penalty 3 cycles，base CPI=1。

  1. 每條指令成為錯誤 branch 的機率 = 0.20×0.10 = 0.02。
  2. 平均額外 cycles/instruction = 0.02×3 = 0.06。
  3. 新 CPI = 1+0.06 = 1.06。

結論：Penalty 必須乘 branch frequency 與 misprediction rate，不能對所有指令直接加 3。

常見誤解

  • 認為 forwarding 能消除所有 RAW hazards。
  • 把 stall 與 flush 當成相同動作。
  • 計算 branch cost 時漏乘 branch frequency。

自我檢核

先在紙上作答，再展開核對。能說明理由，才算真正掌握。

1. 為何 lw 後立刻使用通常仍需 stall？

Load data 到 MEM 結束才可用，比下一指令原定 EX 所需時間晚一個 cycle。

2. Flush 應如何避免錯誤指令改變狀態？

將錯誤指令後續會寫 register 或 memory 的控制訊號清為 0。

講義筆記

Data hazard 的核心是 producer-consumer distance。ALU 結果通常 EX 後可 forward；load 的資料要到 MEM 後才可用，因此緊接使用通常需要一個 stall。

Forwarding 不等於不用 hazard detection。硬體仍需比較 pipeline registers 中的 rs/rt/rd，判斷是否改 ALU input mux。

Branch 越頻繁、prediction 越差，pipeline 效益越容易被 penalty 吃掉。

學習路徑

  1. 觀察問題：先辨認本週主題要解決的現象，例如程式變慢、指令相依、cache miss 或位元解讀錯誤。
  2. 建立模型：把問題抽象成本週核心術語，並畫出資料、控制或位址如何流動。
  3. 套用方法：使用公式、指令格式、pipeline 時序表或 cache 位址切割完成分析。
  4. 檢查結果：確認單位、暫存器內容、控制訊號、hit/miss 或 cycle 數是否一致。
  5. 連回效能：說明這個主題如何影響 CPU time、CPI、correctness 或 memory behavior。
練習任務：給 6 行 MIPS 指令，請標出 RAW hazard、能 forwarding 的地方，以及必須 stall 的地方。

例題與講解

Load-use hazard

lw  $t0, 0($s1)
add $t2, $t0, $s3  # needs loaded data immediately

即使有 forwarding，load data 通常到 MEM stage 結束才可用，因此 add 的 EX stage 需要延後。
