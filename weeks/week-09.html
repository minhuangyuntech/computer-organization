核心概念

  • 複習主軸一：效能：題目常要求比較兩台機器或兩種編譯結果。務必先寫出 CPU Time 公式，再代入 instruction count、CPI、clock rate。
  • 複習主軸二：MIPS：能把陣列、迴圈、if/else、函式呼叫翻成 MIPS，也要能從 MIPS 還原程式意圖。
  • 複習主軸三：資料表示：Two's complement、overflow、sign extension、IEEE 754 是常見觀念題。
  • 複習主軸四：指令編碼：R/I/J format 與控制訊號是下半學期 datapath 的入口。

本週自學導讀

期中整合的核心不是多做相同題型，而是建立固定解題流程：先辨認模型，再列出已知量與單位，逐步更新狀態，最後用另一種觀點檢查答案。

概念推導

四類題目的共同策略

效能題先寫 CPU Time 公式；資料表示題先寫位元寬度與 signedness；MIPS 題先建立變數到暫存器的對照；編碼題先畫欄位邊界。把假設寫在答案上，能避免大多數單位與解讀錯誤。

完成計算後要做量級檢查：GHz 的 cycle time 應在 ns 等級，32-bit 指令應恰好 8 個 hex digits，aligned word address 最低兩 bits 應為 00。

從結果反推合理性

若 clock 更快但程式反而更慢，檢查 instruction count 或 CPI 是否增加；若負數 sign extension 後變正，檢查最高位是否複製；若 loop 永不結束，檢查 branch 條件與 index 更新。

自學時先遮住答案完整做一次，再用答案只定位第一個分歧步驟。直接閱讀完整解答容易產生熟悉感，卻無法驗證自己是否能獨立建立模型。

Worked example

整合比較兩個編譯結果

A：1.2×10^9 instructions、CPI 2、4 GHz；B：1.0×10^9 instructions、CPI 1.8、3 GHz。

  1. A cycles = 1.2×10^9×2 = 2.4×10^9，時間 = 0.6 秒。
  2. B cycles = 1.0×10^9×1.8 = 1.8×10^9，時間 = 0.6 秒。
  3. A clock rate 較高，但 instruction count 與 CPI 的乘積也較高。

結論：兩者同快。任何只引用 clock rate、instruction count 或 CPI 單一數值的結論都不完整。

常見誤解

  • 跳過公式直接代數字。
  • 把 register 名稱與 register number 混用。
  • 看到熟悉題目便略過位元寬度或單位。

自我檢核

先在紙上作答，再展開核對。能說明理由，才算真正掌握。

1. 3 GHz 的 clock cycle time 是多少？

1/(3×10^9) 秒，約 0.333 ns。

2. 32-bit 指令完整寫成十六進位需要幾位？

8 位，因為每個 hex digit 代表 4 bits。

講義筆記

準備期中考時，不要只看答案。請把每題的假設寫清楚，例如單位是 GHz 還是 ns、offset 是 byte 還是 word、數值被解讀為 signed 還是 unsigned。

組合語言題目可逐行加註解，尤其是 branch 的條件與跳躍方向。畫出暫存器內容變化表，錯誤會少很多。

考前最後一輪複習可用三張紙：效能公式表、MIPS 指令表、數值表示規則表。

學習路徑

  1. 觀察問題：先辨認本週主題要解決的現象，例如程式變慢、指令相依、cache miss 或位元解讀錯誤。
  2. 建立模型：把問題抽象成本週核心術語，並畫出資料、控制或位址如何流動。
  3. 套用方法：使用公式、指令格式、pipeline 時序表或 cache 位址切割完成分析。
  4. 檢查結果：確認單位、暫存器內容、控制訊號、hit/miss 或 cycle 數是否一致。
  5. 連回效能：說明這個主題如何影響 CPU time、CPI、correctness 或 memory behavior。
練習任務：用 20 分鐘完成一題效能、一題 MIPS、一題 two's complement、一題 instruction format，之後完成後逐步對答案。

例題與講解

期中混合題練習

CPU A: 1.2e9 inst, CPI 2.0, 4 GHz
CPU B: 1.0e9 inst, CPI 1.8, 3 GHz
A time = 0.6s, B time = 0.6s

兩者執行時間相同。單看 clock rate 或 instruction count 都會得到不完整結論。

課後檢核

  1. 你能不用看筆記寫出 CPU Time 公式嗎？
  2. 你能清楚分辨 `lw` 和 `add` 的資料路徑差異嗎？
  3. 你能解釋 signed overflow 判斷規則嗎？
